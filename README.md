# Tiered (Fabric 1.21.4)
> **Language:** Русский · [English](README.en.md)

## Описание форка
Все права на оригинальный мод принадлежат [Draylar](https://github.com/Draylar/tiered).
Форк и портирование на версию Minecraft **1.21.4** (Fabric / Java 21):
- Портировано на современную систему Data Components Minecraft 1.21.4 (`NbtComponent`, `AttributeModifiersComponent`, `EQUIPPABLE`).
- Обновлена система сетевого взаимодействия на `PayloadTypeRegistry` и `CustomPayload`.
- Заменена старая библиотека `reach-entity-attributes` на нативные ванильные атрибуты 1.21.4 (`player.block_interaction_range`, `player.entity_interaction_range`).
- Поддержка современных конвенциональных тегов предметов `c:*` и ванильных тегов `minecraft:*`.
- Полная русская и английская локализация.

Поддержка: только Fabric!
