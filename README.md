# Tiered (Fabric 1.21.4)
> **Language:** Русский · [English](README.en.md)

## Описание форка
Все права на оригинальный мод принадлежат [Draylar](https://github.com/Draylar/tiered).
Форк и портирование на версию Minecraft **1.21.4** (Fabric / Java 21):
- Портировано на современную систему Data Components Minecraft 1.21.4 (`NbtComponent`, `AttributeModifiersComponent`, `EQUIPPABLE`).
- Обновлена система сетевого взаимодействия на `PayloadTypeRegistry` и `CustomPayload`.
- Заменена старая библиотека `reach-entity-attributes` на нативные ванильные атрибуты 1.21.4 (`player.block_interaction_range`, `player.entity_interaction_range`).
- Поддержка современных конвенциональных тегов предметов `c:*` и ванильных тегов `minecraft:*`.
- Полная русская и английская локализация.

## Оптимизация производительности (Performance)
- **Кэширование атрибутов:** Все допустимые атрибуты и ранги для каждого предмета кэшируются в `ConcurrentHashMap`. Полностью устранены повторные сканирования реестров, разбор тегов и аллокации памяти при каждом запросе модификатора.
- **Оптимизация сущностей предметов (`ItemEntity`):** Устранены непрерывные проверки в каждом тике (`tick()`) для всех лежащих в мире предметов. Ранг генерируется ровно один раз при спавне/установке стака (`setStack`), а не-экипируемые предметы (грязь, камень, семена и т.д.) отсекаются мгновенно.
- **Быстрая проверка NBT-компонентов:** Устранено паразитное копирование NBT-компаундов (`copyNbt()`) при частых проверках наличия ранга у предметов.
- **Zero-Allocation обработка слотов:** Заменены вызовы `Arrays.asList` на прямые итерации по массивам слотов экипировки, исключая создание временных объектов в памяти во время боя и движения.
